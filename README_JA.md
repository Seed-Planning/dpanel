# シードメディカルパネル｜社内操作・運用マニュアル

内容拡充版 4.0 / 2026年9月24日  
画面操作の基準：2026年9月19日確認の操作マニュアル v3.0

## 設置方法

1. 現在のサイトをバックアップし、このZIPを展開します。
2. `seed-panel-manual` フォルダーの**中身一式**を、現在の `index.html` がある場所へアップロードして上書きします。`assets` と `sources` のフォルダー構成は変更しないでください。
3. `index.html`、`styles.css`、`app.js`、`content.js`、`sources.js` が同じ階層にあることを確認します。ビルド、npm、サーバー側プログラム、APIキーは不要です。
4. 公開URLで「退会」「アンケート 開かない」を検索し、ケース・文例・元資料・画像が表示されるか確認します。以前の表示が残る場合はブラウザーの再読み込み／キャッシュ更新を行います。

URLは相対参照とハッシュ形式です。サイト直下・サブディレクトリーのいずれでも使う構成です。従来46ケースのIDを維持しており、既存の `#case=...` リンクを引き続き使用できます。GitHub Pages向けに `.nojekyll` を同梱しています。

## 閲覧と検索

ホームは従来のシンプルなカード形式を継承。「先生からのお問い合わせ」と「社内の操作・業務」を切り替えられます。左メニューの「困りごとを切り分ける」からも、停止している場所や問い合わせ内容を選べます。

検索対象はケース、返信文例・記録ひな形、5資料の本文です。結果のタブを切り替えて確認します。`/` キーで検索欄に移動できます。

ケース内の「文例・ひな形」は開閉式です。「件名・本文をコピー」または「本文だけコピー」で取り出し、今回の事実に合わせて編集します。印刷時は、印刷したい文例を開いてから「印刷する」を選んでください。

## 内容

- 91ケース：元の46ケースを維持し、45ケースを追加。
- 28件の返信文例・配信文面・対応記録／引き継ぎひな形。
- 原資料5点の本文・表・操作画像をサイト内で参照。元のWordも変更せず同梱。
- 退会時の100ポイント単位の個別精算を確認する計算補助。
- 13件の「運用の要確認事項」。資料間の違いと、社内で確定が必要な事項を明示。

「ケース」は日々の業務に合わせて資料を横断した編集です。網羅性のために、ケースだけに入りきらない事項も「資料本文・根拠」から全文を読めるようにしています。収録範囲は `COVERAGE.md` をご覧ください。

## 根拠と優先順位

会員向け条件は利用規約・ポイント利用ガイドライン（2026年5月9日改定）、操作はv3.0（2026年9月19日）を基準にしています。配信メールのデフォルト文言は今回提供の原文を保持しています。

運用・管理マニュアル Draft v0.1（2026年5月10日）は、以前共有された資料を背景参照として収録しています。将来構想・未確定事項・現在の画面と異なる記載を含むため、正式ルールや確認済みの操作より優先しません。Draftが言及する別の仕様書やプライバシーポリシー等、未提供の資料まで収録したものではありません。

新しい対応手順・返信文例は編集案であり、未確認のシステム仕様や社内規程を確定するものではありません。サイト内の「運用の要確認事項」を責任者が確認し、決定した内容は判断者・決定日・根拠とともに更新してください。元資料の版は勝手に置き換えず、変更時に対応ケースと文例を併せて見直します。

## このサイトが行わないこと

このサイトは閲覧用です。会員システムへの接続、会員情報の変更、退会処理、メール送信、ポイント付与・交換処理を実行しません。チェック状態や計算欄への入力を保存・送信しません。チェック欄は確認補助であり、監査証跡ではありません。

文例中の `［ ］` は人が置き換える欄です。配信文面中の `{...}` はシステム用の差し込み記号なので、実際の配信画面とテスト受信で確認してください。

## 社内限定の設置について

既存の認証された環境への設置を前提とし、このZIPに新たな認証機能は追加していません。サイト本体だけでなく `sources` 内のWord、`assets` の画像にも同じアクセス制限を適用してください。公開リポジトリー／認証のない公開サイトへ置かないでください。

`noindex` は検索エンジン向けの指定であり、アクセス制御の代わりにはなりません。外部CDN、外部フォント、分析タグ、生成AI APIへの通信は含みません。
